## Konversi Format Tanggal dengan Moment.js dan JavaScript Manual

Program ini menerima input tanggal dengan format `DD-MM-YYYY` melalui terminal, kemudian mengubahnya menjadi format `DD/MM/YYYY`. Program membandingkan dua pendekatan, yaitu menggunakan library Moment.js untuk memvalidasi dan mengonversi tanggal, serta menggunakan JavaScript bawaan melalui `Date`, `split()`, dan validasi manual. Jika format atau tanggal tidak valid, program akan menampilkan pesan `Format tanggal salah`.

Proyek ini menggunakan Node.js dengan sistem modul ES Modules (`.mjs`) dan ESLint untuk membantu menjaga konsistensi serta kualitas kode JavaScript.
